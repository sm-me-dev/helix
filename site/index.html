🚀 Install Helix

Universal standalone installer with embedded Node runtime (no host Node.js required):

curl -fsSL https://sm-me-dev.github.io/helix/install.sh | sh

Install globally via npm or run directly with npx:

npm install -g @sm-me-dev/helix
npx @sm-me-dev/helix --help

Install via the official Homebrew tap (macOS Apple Silicon/Intel & Linux):

brew install sm-me-dev/tap/helix

Add the official Helix APT repository and install:

curl -fsSL https://sm-me-dev.github.io/helix/install-apt.sh | sudo sh

Install standalone Helix on Windows 10/11 x64:

irm https://sm-me-dev.github.io/helix/install.ps1 | iex

Install via native package managers:

# Windows WinGet winget install sm-me-dev.Helix # Windows Scoop scoop bucket add helix https://github.com/sm-me-dev/helix && scoop install helix # Fedora / RHEL RPM (from Releases) sudo dnf install https://github.com/sm-me-dev/helix/releases/download/v0.1.0/helix-0.1.0-1.x86_64.rpm

💡 Core Architecture & Engineering Principles

⚡ Single-Agent Default

More agents don't mean better code. Helix prioritizes a single capable agent in an isolated worktree, introducing specialist subagents only when proven by benchmarks.

🔒 Zero-Token Verification Gate

helix gate mechanically runs secret scanning, ESLint, TypeScript typechecking, and targeted tests without spending LLM tokens on trivial validations.

🧠 Adaptive Project Knowledge (APKS)

Embedded SQLite FTS5 search indexing repository domains, architecture decisions, and workflows, feeding relevant context strictly within tight token budgets (≤600t).

🛡️ Path Jail & Least-Privilege Guard

Reviews and edits are path-jailed to task worktrees. Reviewers get read-only sandboxes, while sensitive credentials and secrets are automatically redacted.
