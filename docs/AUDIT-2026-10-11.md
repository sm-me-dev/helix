## Verdict

The architecture is sound and should not be redesigned: one pure generator, thin
adapters that emit only verified surfaces, a zero-token deterministic gate, tiered routing
(trivial / standard / complex), and an evals harness that refuses unmeasured claims. The
user's "one subagent per step" idea maps cleanly: manager = main session, scout = read and
clarify, architect = plan and decide, builder = implement, **testing = `helix gate` (no
model)**, reviewer = verify in a fresh window.

What is missing is evidence, not structure. Nothing shows the pack beats no harness
(README now says so), and model subagents have never been exercised in any eval run
(subagent tokens were 0 in all 30 runs of 2026-10-09). The next work is measurement, then
trimming whatever the measurements do not support.

## Open findings, ranked (nothing below was changed)

1. **The F6 matrix has no result.** DECISIONS says it launched 2026-10-10 ~21:50 (60 cells,
   3 arms); `evals/results/` has nothing newer than the 16:05 pilot and no `evals/run.mjs`
   process is running. Treat it as not run. Free-tier opencode is pre-approved; it needs
   ~2 h of wall time and no interactive opencode sessions competing for the machine.
2. **Reviewer cannot verify what it must verify.** Its body says PASS only if success
   criteria "were actually run", but its tools are `Read` (+ Graphify). It can only trust
   output the Builder pasted, which contradicts "treat it as untrusted". Option: give it
   `Bash` plus a frontmatter `PreToolUse` hook that exits 2 unless the command is
   `node .helix/gate.mjs` (documented mechanism; works for repo-local agents, ignored for
   plugin agents, needs folder trust). Zero model tokens for the check itself.
3. **Subagents pay for `AGENTS.md` on every spawn.** Docs: a custom subagent loads the
   CLAUDE.md hierarchy and `AGENTS.md` unless `omitClaudeMd: true` (Claude Code 2.1.271+).
   Scout, architect and reviewer take everything from the 12-line handoff card; the builder
   needs the repo facts. Candidate: `omitClaudeMd: true` on the three, with the gate command
   in the card. Static cost is measurable (AGENTS.md is ~344 tokens in the scratch pack);
   the effect on pass rate is not, so it needs an F6 arm before shipping.
4. **No runaway cap.** No agent sets `maxTurns` (documented field; output is marked partial
   and resumable). A looping scout or reviewer has no ceiling. Pick values from the F6
   transcripts, not by feel.
5. **`init` points agents at a graph it does not build.** With Graphify on PATH and 20+
   files, the pack says "Graph first: query_graph …" and `doctor` fails on
   `graphify-out/GRAPH_REPORT.md` until the user runs `graphify update .`. First session
   hits a missing index. Either run the index step in `init` (opt-out) or print it as the
   last line and keep `graph-first` off until the index exists.
6. **The gate is advisory outside Claude Code and Codex.** Only their Stop hooks enforce
   it; Cursor, Copilot, OpenCode and Antigravity rely on one AGENTS.md line. An
   agent-agnostic backstop is a generated CI workflow (and optional pre-push hook) that runs
   `node .helix/gate.mjs`. Action versions must be SHA-pinned, as this repo's own CI is.
7. **Secret denies cover only `.env*` and `**/secrets/**`.** Nothing for `~/.ssh`, `~/.aws`,
   `*.pem`. Verify that `Read` deny rules accept paths outside the repo before adding any.
8. **Role descriptions still say "graph-cited"** in packs without Graphify (known residual,
   2026-10-10). Descriptions are what the parent reads to delegate, so this is the
   highest-leverage place for the fix.
9. **`docs/DECISIONS.md` is 1,523 lines and not chronological** (2026-10-09 entries sit
   after 2026-10-07 Phase 4, F-series entries repeat). Keep it append-only but split by
   month under `docs/decisions/` with a one-screen index.
10. **Local leftovers from the Grok workspace** (untracked or ignored, not in git):
    `.vercel/`, `.tanstack/`, `.grok/`, `screenshots/`, `artifacts/`, plus Grok lines in
    `.graphifyignore`. Deleting needs your approval; `.husky/post-*` rebuild the graph on
    every commit and are worth a second look.
11. Roles are unmeasured per tier: architect and reviewer run on `opus` for every complex
    task. Keep the tier design, but F6 should price each role before it is a default.
